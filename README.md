# 📱 手机视频浏览器（纯网页端）

一个**纯前端**的短视频浏览器，专为安卓手机网页设计。选择手机里的视频后，即可像刷短视频一样**上下滑动切换**。

## 特点

- **纯网页端**：单个 `index.html`，无需后端、无需安装 App。
- **不上传、不联网**：视频通过浏览器本地选择（`<input type="file">`），全程在本机播放，选完后可在飞行模式下浏览。
- **短视频体验**：全屏播放 + CSS 滚动吸附（scroll-snap），上下滑动一次切一个视频。
- **当前视频自动播放**：滑到哪个就播哪个（IntersectionObserver），其它自动暂停。
- **移动端适配**：竖屏全屏、安全区适配、`playsinline` 内联播放、点击暂停/播放、进度条、静音开关。

## 为什么是"选择"而不是"自动扫描"？

出于安全限制，**网页无法擅自扫描手机存储**里的所有文件。所有浏览器都要求用户主动授权选择。本项目用的是各安卓浏览器都支持的文件/文件夹选择方式，最稳定可靠：

- **选择视频文件**：可多选若干个视频。
- **选择整个文件夹**：通过 `webkitdirectory` 选中相册或某个目录下的全部视频。

## 使用方法

1. 把本项目部署到任意静态托管（GitHub Pages、Vercel、Netlify…），或直接把 `index.html` 传到手机用浏览器打开。
2. 用**安卓 Chrome** 打开页面。
3. 点击「选择视频文件」或「选择整个文件夹」，挑选手机里的视频。
4. 上下滑动切换视频；点击屏幕暂停/播放；右上角按钮开关声音、继续添加视频。

### 用 GitHub Pages 部署

在仓库 Settings → Pages 中选择该分支并保存，几分钟后即可通过 `https://<用户名>.github.io/<仓库名>/` 在手机上访问。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 上 / 下滑动 | 切换上一个 / 下一个视频 |
| 点击屏幕 | 暂停 / 播放 |
| 右上角喇叭 | 开 / 关声音（移动端默认静音以允许自动播放，点一下即可开声音） |
| 右上角加号 | 继续添加更多视频 |
| 键盘 ↑ ↓ / 空格 / M | 桌面调试用：切换 / 播放暂停 / 静音 |

## 支持的格式

取决于浏览器解码能力，常见的 `mp4`、`mov`、`webm` 支持最好；`mkv`、`avi` 等部分机型可能无法播放。

## 兼容性提示

- 推荐 **Chrome for Android**。
- 移动端浏览器有声自动播放受限，所以首次进入默认静音，**点一下喇叭或屏幕即可开声音**。
